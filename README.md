# 🚩 श्री सुरभी गो-आश्रम व गौसेवा व्यवस्थापन पोर्टल
*(Shree Surbhi Gau-Ashram & Gaushala Management Portal)*

हा देशी गोवंश संरक्षण, संवर्धन, देणगी व्यवस्थापन आणि सेंद्रिय उत्पादने विक्रीसाठी तयार केलेला एक द्विभाषिक (मराठी व इंग्रजी) वेब ॲप्लिकेशन प्लॅटफॉर्म आहे.

---

## 📌 प्रकल्पाची प्रमुख वैशिष्ट्ये (Key Features)

### १. ग्राहक व भाविक पोर्टल (Customer Portal)
* **तातडीची अंत्यविधी गोवऱ्या सेवा (Emergency Funeral Ritual Support):** 
  * अंतिम संस्कारासाठी लागणाऱ्या शुद्ध सुकलेल्या गोवऱ्या थेट स्मशानभूमीत अवघ्या २ तासांत पोहोचवण्यासाठी तात्काळ ऑर्डर सुविधा.
* **गौ-उत्पादने ई-दुकान (Organic Gau-Products Store):** 
  * A2 वैदिक बिलोना तूप, ताजे दूध, शेणाच्या गोवऱ्या, धूपबत्ती, गोमूत्र अर्क आणि सेंद्रिय खतांची खरेदी (कार्ट व चेकआऊटसह).
* **ऑनलाईन गौदान व चारा देणगी (Online Donations & Instant Receipt):** 
  * १ दिवसाचा चारा, आजारी गोवंश उपचार, किंवा गाय दत्तक योजनेसाठी देणगी.
  * देणगी पूर्ण झाल्यावर तत्काळ प्रिंट / PDF फॉरमॅटमध्ये **अधिकृत देणगी पावती (80G Receipt)** डाऊनलोड पर्याय.
* **गोवंश दत्तक व समर्पण (Adoption & Surrender):** 
  * शेती किंवा पालनासाठी गोवंश दत्तक मागणी अर्ज.
  * निराधार, वृद्ध, किंवा आजारी गोवंश आश्रमात दाखल करण्यासाठी समर्पण अर्ज.
* **द्विभाषिक सपोर्ट (Bilingual Switcher):** 
  * हेडरमधील एका क्लिकवर मराठी (MR) आणि इंग्रजी (EN) भाषा बदलण्याची सोय.

### २. ॲडमिन व्यवस्थापन डॅशबोर्ड (Admin Dashboard)
* **रिअल-टाईम KPIs:** एकूण जमा देणग्या, उत्पादनांच्या ऑर्डर्स, अंत्यविधी मागण्या आणि एकूण गोवंश संख्या.
* **ऑर्डर्स व्यवस्थापन:** सर्व ऑर्डर्सची स्थिती (Pending, Packed, Delivered) बदलणे.
* **देणगी वही (Donations Ledger):** सर्व देणग्यांची नोंद, पावती पुन्हा प्रिंट करणे आणि डेटा CSV/Excel मध्ये डाऊनलोड करणे.
* **गोवंश नोंदवही (Cattle Registry):** टॅग नंबर, जात, वय, आणि आरोग्य स्थितीसह नवीन जनावराची नोंद करणे.
* **उत्पादन व साठा व्यवस्थापक (Inventory Management):** 
  * नवीन उत्पादने थेट जोडणे.
  * शिल्लक साठा (Stock Quantity) स्वतः मॅन्युअली टाईप करून सेव्ह करणे.

### ३. डेटा व्हॅलिडेशन (Strict Validation)
* मोबाईल नंबरमध्ये केवळ १० अंक स्वीकारले जातात (अक्षरे आपोआप ब्लॉक होतात).
* नावाच्या फील्ड्समध्ये आकडे (0-9) ब्लॉक केले जातात.

## 🛠️ वापरलेले तंत्रज्ञान (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript (ES6+ Vanilla JS)
* **CSS Framework:** Tailwind CSS (CDN)
* **Icons:** Font Awesome 6
* **Typography:** Google Fonts (Noto Sans Devanagari & Poppins)
* **Data Storage:** LocalStorage Engine (कोणत्याही बाह्य सर्व्हरशिवाय थेट ब्राऊझरमध्ये डेटा सुरक्षित राहतो)
